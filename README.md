# Faroug’s Learning Galaxy — Voice Fix Edition

## Download and play

**[Download the complete game ZIP](https://github.com/habbaninho888-ui/Faroug-Education-Game/raw/refs/heads/main/downloads/Farougs-Learning-Galaxy-Voice-Fix.zip)**

1. Download the ZIP. If GitHub shows a file page, click **Download raw file**.
2. Extract it (Windows: **Extract All**; macOS: double-click).
3. Open `Farougs-Learning-Galaxy-Voice-Fix.html` in **Chrome or Edge**.
4. Click an activity or a voice preview to enable audio.

The HTML contains the complete game and **282 English and Arabic neural narration clips**. No installation, account, API key or installed Arabic voice is needed. Keep **Included neural voices** and **Natural** pace selected in Settings.

Core activities and included narration work offline. Optional Qur’an recitation needs internet and remains authentic recorded recitation, not synthesized speech.

## Voice repair

- Arabic narration plays without relying on an installed device voice.
- English uses Kokoro `af_heart` neural audio.
- Automatic feedback waits for the current phrase instead of cutting it off.
- Replay, navigation, mute and backgrounding stop current speech safely.

The voices are synthesized neural audio, not human actors’ recordings. Arabic voice assets use **CC BY-NC-SA 4.0** and are provided for **personal, noncommercial use**. Credits and full license copies are inside the ZIP.
