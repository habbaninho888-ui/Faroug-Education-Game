# Android and iOS

Both projects bundle the same offline platform, including the runner and narration. No hosted website is required. Package ID: `com.faroug.learninggalaxy`; version: 2.0. Native export uses the system share sheet and temporary app cache. Backgrounding stops speech/recitation and pauses games; Android Back closes an open dialog or returns home. No microphone permission is requested. Android cloud backup is disabled.

## Android

Requires Node 22+, a full Java 21 JDK, Android SDK platform 35 and build tools 35.0.0.

```sh
npm ci
npm run mobile:sync
cd android
./gradlew assembleDebug
```

Output: `android/app/build/outputs/apk/debug/app-debug.apk`. Debug builds are for device testing, not Play Store publication. Install with `adb install -r <apk>`, or transfer to an Android device and allow installation from your trusted file source. A debug key is generated by the Android tools; no production signing key is included.

The verified build from this workspace is `downloads/Farougs-Learning-Galaxy-Android-debug.apk`. It compiled successfully and passed APK signature verification; physical-device testing remains pending.

For release, open `npm run android`, configure your application ID/signing, and generate a signed AAB. Check the current Play target SDK requirement before submission; this project targets API 35. Review the bundled noncommercial Arabic audio license before distribution.

## iOS

Requires macOS, Xcode with iOS SDK, CocoaPods, and Node 22+.

```sh
npm ci
npm run mobile:sync
npm run ios
```

Open `ios/App/App.xcworkspace` after pod installation, select a simulator or connected device, and build. Set your Apple development team in Signing & Capabilities. For distribution, archive and export through Xcode with your signing profile and App Store Connect account.

This Linux environment cannot compile iOS, produce a signed IPA, or run the iOS simulator. The generated project includes icons, splash assets, plugin configuration, and the Filesystem privacy manifest. It needs Xcode and physical iPhone validation.
