# Qur’an text and recitation sources

The offline text library contains all 114 surahs and 6,236 numbered verses, copied verbatim from Quran JSON **v3.1.2**, by **Risan Bagja Pradana**. The pinned source identifies its Arabic text as Uthmani text from **The Noble Qur’an Encyclopedia (QuranEnc)**. This is Hafs numbering, matching the linked per-ayah recitation files. No translation or generated transliteration is shown as Qur’an text; the English names are chapter-name transliterations from the source.

- Source release: <https://github.com/risan/quran-json/tree/v3.1.2>
- Source file: <https://raw.githubusercontent.com/risan/quran-json/v3.1.2/dist/quran.json>
- Upstream text credit: <https://quranenc.com/en/home>
- Retrieved source SHA-256: `d8a8adff387f60ce3ff7dbe3238dd9b27120bfe29d8fcb07ad2e89cad37cefd4` (a record of the downloaded, TLS-verified source; not a separate publisher signature).
- Dataset license: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), full copy in `assets/quran/Quran-JSON-CC-BY-SA-4.0.txt`.

Verse strings retain the source's Uthmani diacritics and orthography. Compared with the original game's last-three-surah text, the writing system differs slightly while normalized words remain equivalent. Counts, chapter numbering, and the last three surahs are checked structurally; this is not a religious-text certification. For formal study use a trusted mushaf and qualified teacher.

Recitation links go to **EveryAyah** and are authentic recordings, not speech synthesis. Choices: **Mishary Rashid Alafasy (128 kbps)**, **Mahmoud Khalil Al-Husary (128 kbps)**, and **Abdul Basit Abdus Samad, murattal (192 kbps)**. Audio files are not copied into this project, and online playback requires access to `everyayah.com`.
